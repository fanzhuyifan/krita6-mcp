Krita 6 MCP Bridge

This plugin connects an external MCP client to Krita 6 through a local authenticated bridge. It is alpha software. The verified native workflow uses Linux/Krita 6.0.3; consult the repository's validation record for supported brushes, color spaces, and remaining limits.

Connect

Install the external Python package from the same release, configure your MCP client to run python -m krita6_mcp.cli serve using that environment's absolute Python path, and run krita6-mcp doctor --json to check discovery.

The enabled plugin starts automatically. Start, Stop, and Status actions are under Tools → Scripts. Set KRITA6_MCP_AUTOSTART=0 in Krita's environment before launch to start manually. Stopping waits for already dispatched native work to settle.

Save and export

Configure named output directories in Krita's environment before starting the application:

KRITA6_MCP_OUTPUT_ROOTS='{"art":"/absolute/path/to/artwork"}'

The directory must already exist. File tools accept a root name and relative path, with explicit overwrite permission. No output roots are needed for inspection, painting, or inline previews.

Reference editing

Commands can activate an existing document view, clear or replace a selection, inspect a canvas crop, copy and reorder paint layers, set visibility/name/opacity, and align an overlay with a bounded pixel transform. Native cubic Bézier paths use the selected pixel-brush preset. Layer and selection edits do not promise an undo transaction; duplicate an important layer before transforming it.

To open PNG/JPEG/KRA files or import a PNG/JPEG layer, configure separate existing input directories before launching Krita:

KRITA6_MCP_INPUT_ROOTS='{"references":"/absolute/path/to/references"}'

Use the named root and a relative path. Imports and transforms require the documented RGBA/U8/sRGB color space and fit the complete result inside the canvas. Building a plugin update does not change an already running instance; install and restart when you are ready.

Operation outcomes

Reuse the same operation ID and arguments when retrying uncertain work. A timeout does not undo an edit. Check operation status before issuing another mutation. Painting requires the requested document's active view and a supported, unlocked paint layer. Optional AI Diffusion tools use an already loaded compatible add-on and connected local backend. Poll generation separately, inspect the returned image, then explicitly apply it as a new layer. Backend cancellation is not exposed.
